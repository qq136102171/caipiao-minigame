# 微信小程序发布完整指南

本文档说明如何把 `caipiao-miniprogram/` 发布到微信小程序平台。  
**整个流程约需 1-2 周**（含审核等待时间）。

---

## 0. 流程概览

```
注册小程序账号 ─→ 主体认证 ─→ 拿 AppID ─→ 填到项目 ─→ 开发者工具上传 ─→ 提交审核 ─→ 发布
   │                                                       │
   └──── 你亲自做（实名 / 验证）─────────────────────────┘── 你亲自做（点上传）
                              │
                              └── 我能帮你做的（✓ 已完成）
                                  ├─ 项目代码（caipiao-miniprogram/）
                                  ├─ 静态检查（make mp-ci）
                                  ├─ 用户协议页（pages/agreement/）
                                  ├─ 隐私政策页（pages/privacy/）
                                  ├─ 一键填 AppID 脚本（scripts/setup-appid.sh）
                                  └─ 本指南
```

---

## 1. 注册微信小程序账号

1. 打开 <https://mp.weixin.qq.com/>
2. 点右上角"立即注册" → 选择"小程序"
3. 填写基本信息（邮箱必须是未注册过微信公众平台的）
4. 邮箱激活 → 进入主体认证

### 1.1 主体类型选择（关键！）

| 类型 | 个人 | 个体工商户 | 企业 |
| --- | --- | --- | --- |
| 资质材料 | 身份证 + 微信扫码 | 营业执照 + 身份证 | 营业执照 + 对公账户验证 |
| 审核周期 | 1-3 天 | 1-3 天 | 1-7 天 |
| 可发布类目 | 限制多（详见下） | 多 | 多 |
| 个人支付 | ❌ | ✅ | ✅ |
| 适用本项目 | ⚠️ 有限制 | ✅ 推荐 | ✅ 最佳 |

> ⚠️ **本项目"彩票"类目是敏感类，个人主体可能被拒**。建议选择**个体工商户**或**企业**主体。

### 1.2 个人主体的限制

**个人主体不能直接发布"彩票"类小程序**，但可以：

- 改名为"彩票号码生成器"、"号码参考工具"等不含"投注/购买/中奖"的名称
- 选择类目为"工具 → 效率" 或 "工具 → 信息查询"
- 在小程序简介中**强调娱乐属性**，不引导购买

> 即使改了名字，部分审核员仍可能以"涉及彩票"为由拒绝。如被拒可走"申诉"渠道说明工具属性。

---

## 2. 拿 AppID

认证通过后：

1. 登录 <https://mp.weixin.qq.com/>
2. 左侧菜单 → **开发** → **开发管理** → **开发设置**
3. 复制 **AppID（小程序ID）** — 形如 `wx1234567890abcdef`
4. （可选）生成 **AppSecret（小程序密钥）** — 用于服务端 API，本项目离线不需要
5. 记下服务器域名（如果将来要加后端 API）

---

## 3. 填入 AppID

```bash
# 在项目根目录
bash scripts/setup-appid.sh wx你的AppID
# 例如：
bash scripts/setup-appid.sh wx1234567890abcdef
```

脚本会自动更新：
- `caipiao-miniprogram/project.config.json`
- `caipiao-miniprogram/project.private.config.json`

验证：
```bash
grep -r "wx" caipiao-miniprogram/project.config.json caipiao-miniprogram/project.private.config.json
```

如果填错了想恢复游客模式：
```bash
bash scripts/setup-appid.sh --clear
```

---

## 4. 在开发者工具里打开 + 配置

### 4.1 打开项目

1. 启动**微信开发者工具**
2. 左侧"小程序"图标 → "导入项目"
3. 选择目录：`caipiao-miniprogram/`
4. AppID 应自动填入（步骤 3 设的）
5. 项目名称：`发财致富记录器`
6. 后端服务：**不启用**（纯前端）
7. 点"导入"

### 4.2 第一次打开

- 项目编译约 5-10 秒（首次构建）
- 默认会打开模拟器，看到首页
- 点右上角"预览" → 扫码可在真机上看效果

### 4.3 配置小程序后台信息

登录 [微信公众平台](https://mp.weixin.qq.com/) → **设置 → 基本设置**：

| 字段 | 填写 |
| --- | --- |
| 小程序名称 | `发财致富记录器`（或别的） |
| 简介 | `仅供娱乐参考的离线选号工具，无网络依赖` |
| 头像 | 建议 144×144 圆形 logo |
| 类目 | 工具 → 效率 / 信息查询（个人主体） |

**设置 → 第三方设置 → 隐私政策**：
- 填一个 HTTPS URL，指向你的"隐私政策页"
- 本项目的 `pages/privacy/index` 是**小程序内**页面，不能直接作为 URL
- 你可以把这个页面部署到 GitHub Pages / Vercel / Netlify 等免费静态托管
- 或者挂到一个已有 HTTPS 网站下

**开发 → 开发管理 → 开发设置 → 服务器域名**：
- 本项目是纯前端，**不需要**配置
- 如果以后加了云开发 / 后端，再来填

---

## 5. 上传代码

在开发者工具里：

1. 右上角点"**上传**"按钮
2. 填写版本号：`1.0.0`
3. 填写项目备注：`首版 · 仅娱乐`
4. 点"上传"
5. 上传成功后会显示"代码已上传到后台"

**首次上传需扫码登录**（用注册时的微信扫码）

---

## 6. 提交审核

登录 [微信公众平台](https://mp.weixin.qq.com/)：

1. 左侧菜单 → **版本管理**
2. 找到刚上传的版本（开发版本）
3. 点"提交审核"
4. 填写：
   - 功能页面截图（5 张，参考下面的"截图准备"）
   - 测试账号（如有登录功能）
5. 提交

### 6.1 截图准备（关键！）

审核需要 5 张截图：

| # | 内容 | 建议 |
| --- | --- | --- |
| 1 | 首页（选号前） | 模拟器截图 |
| 2 | 首页（生成号码后） | 模拟器截图 |
| 3 | 历史命中分析面板展开 | 模拟器截图 |
| 4 | 用户协议页 | 模拟器截图 |
| 5 | 隐私政策页 | 模拟器截图 |

可以在模拟器里用 `caipiao-miniprogram/preview.html` + Chrome 截图替代，或直接在开发者工具模拟器里截图。

### 6.2 审核时长

- 个人主体：通常 **1-3 天**
- 企业/个体户：通常 **1-7 天**

---

## 7. 发布上线

审核通过后：

1. 微信公众平台 → 版本管理 → 找到"审核通过的版本"
2. 点"**发布**"
3. 几分钟后即可在微信里搜索到

---

## 8. 常见被拒原因 + 规避

### 8.1 提示"含彩票相关功能"

**原因**：审核员认为涉及"彩票投注"。  
**规避**：
- 把名字改为不含"投注"（如"号码参考工具"）
- 在简介强调"娱乐参考"
- 提供"仅供娱乐、不构成购买建议"的免责声明（本项目已包含）

### 8.2 提示"未提供隐私政策"

**原因**：没填隐私政策 URL。  
**规避**：
- 在微信公众平台 → 设置 → 第三方设置 → 隐私政策，填一个 HTTPS URL
- URL 可以是 GitHub Pages 上的 `pages/privacy/index.html`

### 8.3 提示"类目不符"

**原因**：选择的服务类目与小程序实际功能不匹配。  
**规避**：
- 个人主体：选择"工具 → 效率"
- 企业/个体户：可选择"工具 → 信息查询"

### 8.4 提示"代码包超过 2MB"

**原因**：主包或子包超限。  
**规避**：
- 本项目当前 < 200KB，远未触达上限
- 如果以后加了大量资源（图片/视频），用**分包加载**

## 9. 发布后的维护

### 9.1 提交新版本

```bash
# 改了代码后
make mp-ci          # 跑检查
make mp-upload MP_VER=1.0.1 MP_DESC="修复xxx"
```

或在开发者工具里点"上传"，版本号递增。

### 9.2 看用户反馈

- 微信公众平台 → 反馈管理
- 微信公众平台 → 用户分析（看 UV / PV）

### 9.3 下架 / 暂停服务

- 微信公众平台 → 版本管理 → 选版本 → "下架"

## 10. 进阶：使用 MCP 自动上传

如果你启用了 `wechat_devtools` MCP server：

```bash
# Codex 会自动调这些工具
mcp__wechat_devtools__open     # 打开项目
mcp__wechat_devtools__preview  # 生成预览二维码
mcp__wechat_devtools__upload   # 上传代码（替代手动点上传按钮）
```

但**注意**：MCP 的 `upload` 在某些版本下可能不直接工作，可能仍需在开发者工具里手动点。

## 附录：常见问题

**Q：没有公司能发布吗？**  
A：可以，用个人主体或个体工商户。个人主体限制多，**建议注册个体工商户**（不需要办公室，几百块搞定）。

**Q：审核被拒后还能再提交吗？**  
A：可以，修改后再上传新版本即可。每个版本可重试 3 次。

**Q：小程序可以改名字吗？**  
A：每年可改 5 次。发布前可改，发布后改需要审核。

**Q：用户访问数据我能看到吗？**  
A：在微信公众平台 → 用户分析里看。

**Q：可以加广告变现吗？**  
A：可以。开通"流量主"功能，个人主体累计 1000 独立访客后可申请。
